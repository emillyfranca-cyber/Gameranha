Sobre o disparador físico

O site usa a API Web Serial do Chrome/Edge para receber o comando SHOOT pela USB. O microcontrolador precisa enviar SHOOT\n quando o gatilho for acionado. O firmware exato depende da placa e do circuito de vocês.
