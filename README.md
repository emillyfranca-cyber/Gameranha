# WEB HERO — Mundo SENAI v5

## O que mudou
- O boneco vermelho simplificado na parte inferior da arena foi substituído pela imagem transparente do Homem-Aranha enviada pela equipe.
- A imagem está em `assets/hero-avatar.png` e é exibida no centro inferior da arena.
- O restante do jogo, ranking local, personagens, cenário e suporte experimental a disparador serial foram mantidos.

## Como executar
1. Extraia o ZIP inteiro em uma pasta.
2. Abra a pasta no VS Code.
3. Execute `index.html` com Live Server.

Mantenha a pasta `assets` junto dos arquivos HTML, CSS e JavaScript para que as imagens carreguem.
